# おかしならべ

3人で遊ぶ、お菓子の並べゲームです。

**▶ ここで遊べます：https://mataasobo.com/okashi-narabe/**

ダウンロードして `index.html` をブラウザで開いても遊べます（インストール不要）。`index.html`・`rules.js`・`cpu.js`・`room.js` は同じフォルダに置いてください（手元で開いたときの友人戦は、`server/` で `npx wrangler dev` を動かしているときだけ使えます）。

## 遊び方

- 盤は6×6、手持ちのお菓子は1人6個。自分の番に、次のどれか1つをします。
  - **置く**：手持ちのお菓子を空いているマスに置く
  - **動かす**：盤の自分のお菓子を、となりの空いているマスへ動かす（ななめもOK）
  - **入れかえ**：自分のお菓子を、となりの相手のお菓子と入れかえる（何回でもOK）
- 同じお菓子が**4つ並ぶと食べられて1点**。食べたお菓子は手持ちに戻ります。5つ並びは2点。
- 入れかえられた**相手のお菓子は一目ぼれして「恋モード」**（目がハート）になります。
- **ふつう同士**、**恋モード同士**なら入れかえOK。ふつうと恋モードは入れかえられないので、入れかえ返しはできません。恋モード同士で入れかえると、入れかえられた相手のお菓子は**目がさめて**ふつうに戻ります。空きマスへ動かすのはいつでもOK。
- **恋ボーナス**：自分の**恋モードのお菓子を動かして**（恋モード同士の入れかえもOK）揃えたら**＋1点**。入れかえられて恋モードにされたお菓子が、反撃の切り札になります。
- 先に**3点**取った人の勝ち。150手で時間切れになり、その時点で点が多い人の勝ち。

盤の大きさ（5×5・6×6・7×7）・並べる数・手持ちの数・恋ボーナスのあり／なし・目標点は画面下で変えられます。各プレイヤーは「人」と「CPU」を切り替えられます。
CPUの強さは「やさしい／ふつう／つよい」から選べます（ゲームの途中でも変えられます）。

- **やさしい**：目の前だけ見る。揃える・相手の「あと1つ」をふさぐ・自分の「あと1つ」を増やす
- **ふつう**：1手先を全部試して、自分と相手の「あと1つ」の数で選ぶ。動かした跡や入れかえで相手に道を開けないかも見る
- **つよい**：2手読み。よさそうな手を10個にしぼり、それぞれに次の人の一番いい返しを当ててから選ぶ。「ふつう」2人を相手に70%勝つ（互角なら33%）

「つよい」同士は守りが固すぎて引き分けやすいので、「つよい」と遊ぶなら7×7がおすすめです。

手持ちを7個に増やすと、試合が短くなり初心者も勝ちやすくなりますが、「動かす」はほとんど使われなくなります（6×6で1試合8回→3回）。じっくり考えるなら6個、気楽に遊ぶなら7個がおすすめです。
慣れてきたら7×7がおすすめです。上手い人同士だと、6×6では守りきられて引き分けが増えていきますが、7×7なら決着がつきやすくなります。
操作はドラッグでも、タップで選んでからタップでもできます。

### みんなと遊ぶ（友人戦）

「👫 みんなと遊ぶ」を押すと部屋の一覧が出ます（人待ち → 途中参加OK → 対戦中 の順）。部屋を選ぶか「＋ 部屋を作る」で部屋に入ります。部屋を作ると招待リンク（`?room=…`）が出るので、友達に送って呼ぶこともできます。部屋を作った人は「一覧に出す」を外すと、リンクを知っている人だけの部屋にできます。一覧に出るのは、誰かがいる部屋だけです。

部屋に入った人は名前を入れて空いている席に座ります。部屋を作った人が「はじめる」を押すと、空いた席にはCPU（ふつう）が入って始まります。始まったあとに来た人は、CPUの席と交代して途中から参加できます（見るだけもできます）。盤はサーバーに保存されるので、全員がそろっていればその場で、そろっていなければ空いた時間に開いて1手ずつ打てます（自分の番になると、タブの名前が「★あなたの番！」になります）。終わったら、座っている人が全員「もう一回」を押すと再戦です。友人戦のルールは6×6・4つ並べ・手持ち6・恋ボーナスあり・3点先取で固定です。

サーバーは Cloudflare Workers と Durable Objects（`server/`、部屋1つが Durable Object 1つ、部屋の一覧は Lobby という Durable Object 1つ）。手の正しさはサーバーが `rules.js` で確かめます。CPUの手は、部屋にいる人のブラウザが `cpu.js` で考えてサーバーに送ります（無料プランは1回の計算時間が短いため）。

### スタンプ

盤の下のボタンで、8種類のスタンプ（よろしく！・ナイス！・ドキッ・えっ！？・やられた〜・ぐぬぬ・ありがと・もう一回！）を送れます。自分のお菓子がその表情で、名前カードの上に出ます。友人戦ではほかの人の画面にも届きます（サーバーは中継するだけで保存しません）。CPUも、入れかえられた・揃えられた・勝った負けたときにスタンプを返します（同じCPUは6手に1回まで。どの画面でも同じになるよう、くじは使いません）。

### 広告用デモ（`?demo`）

URLの最後に `?demo` を付けて開くと（例：`index.html?demo`）、CPU同士の試合を裏で何十本も回し、**負けていた人が恋ボーナスで決勝点を取って勝つ試合**を選んで再生します。設定やルールの説明は隠れ、1試合（40〜50秒）終わると次の試合を探してまた再生します。画面録画して広告の素材にするためのモードです。音を出すには、始まったあとに画面を1回クリックしてください。

## ファイル

| ファイル | 中身 |
|---|---|
| `index.html` | 画面・演出・操作。ルールとCPUは下の2つを呼ぶだけ |
| `rules.js` | ルールだけ（置く・動かす・入れかえ、食べる・点数、次の番・時間切れ）。画面のことは何も知らず、ブラウザでも Node でも動く |
| `cpu.js` | CPU（やさしい・ふつう・つよい）。`rules.js` だけを使う |
| `room.js` | 友人戦の通信（部屋を作る・つなぐ・つなぎ直す）。画面のことは何も知らない |
| `server/` | 友人戦のサーバー。`src/game.js` が部屋のルール（席・開始・1手・再戦）、`src/worker.js` が通信と部屋の一覧。`npm test` で部屋のルールを試し、`npx wrangler dev` で手元で動かし、`npx wrangler deploy` で api.mataasobo.com に出す。`node try-live.js <URL>` で、動いているサーバーに2人でつないで1試合打てる |
| `tools/skill-test.js` | CPU同士を大量に戦わせて、実力差がどれくらい勝敗に出るかを調べるスクリプト |
| `tools/love-bonus-test.js` | 恋ボーナスのあり／なしをCPU同士で比べるスクリプト |
| `tools/hand-size-test.js` | 手持ちの数で、時間切れや「動かす」の割合がどう変わるかを調べるスクリプト |
| `docs/` | [アイデア帳](docs/ideas.md)、調べたことの記録（[手持ちの数と時間切れ](docs/hand-size.md)） |

見た目を変えるときは `index.html` だけ、ルールを変えるときは `rules.js`（とCPUの考え方を `cpu.js`）だけを直します。`tools/` のスクリプトもゲームと同じ `rules.js` と `cpu.js` を使うので、ルールを変えたらそのまま試せます。

## 実力はあるのか

`node tools/skill-test.js 600` で、強さの違うCPUを600試合ずつ戦わせました（1人 対 2人、席は公平に回す。6×6・4つ並べ・手持ち6・目標3点・恋ボーナスあり。「つよい」は遅いので300試合）。

| 1人の側 | 相手2人 | 1人の側の勝率 |
|---|---|---|
| つよい | ふつう | 70% |
| ふつう | やさしい | 75% |
| やさしい | ふつう | 17% |
| やさしい | 欲張り | 100% |
| やさしい | 適当 | 99.8% |

実力差がなければ33%なので、実力ははっきり勝敗に出ます。「欲張り」は揃えられるときだけ揃えてあとは適当、「適当」はランダムに打つ、比べるための頭です。

「やさしい」と「ふつう」の差は、**動かした跡に空いたマスを次の人に使われないか**を見るかどうか。上達のコツはそこです。

## 恋ボーナスは狙える技か

`node tools/love-bonus-test.js 600` で、「ふつう」のCPU 3人を600試合ずつ戦わせました（6×6・4つ並べ・手持ち6・目標3点）。ボーナスを知らないCPUは、ボーナスなしのつもりで打ちます。

| | ボーナスなし | 恋ボーナスあり |
|---|---|---|
| ボーナスを**知っている1人**の勝率（知らない2人が相手） | — | 39%（互角なら33%） |
| ボーナスがついた並び | — | 14% |
| 「動かす」の割合 | 11% | 16% |
| 入れかえの割合 | 37% | 44% |
| 1試合の手数（中央値） | 64 | 75 |

知っていると勝てるので、運ではなく狙って取る技になっています。ほとんど使われなかった「動かす」にも出番ができました。

ボツにした案：「並びに自分の恋モードのお菓子がT個以上入っていたら＋1点」。恋モードにされるのは相手に入れかえられたときだけなので自分では増やせず、知っていても勝率は33〜35%のまま（ただの運）でした。T=1だと6割の並びで出てしまい、2番目の席の勝率が25%まで落ちました。

# おかしならべ

3人で遊ぶ、お菓子の並べゲームです。

**▶ ここで遊べます：https://sphosino.github.io/okashi-narabe/**

前身の花火版「3人で三目並べ」はこちら：https://sphosino.github.io/okashi-narabe/sanmoku3.html

ダウンロードして `index.html` をブラウザで開いても遊べます（インストール不要）。

## 遊び方

- 盤は6×6、手持ちのお菓子は1人6個。自分の番に、次のどれか1つをします。
  - **置く**：手持ちのお菓子を空いているマスに置く
  - **動かす**：盤の自分のお菓子を、となりの空いているマスへ動かす（ななめもOK）
  - **入れかえ**：自分のお菓子を、となりの相手のお菓子と入れかえる（何回でもOK）
- 同じお菓子が**4つ並ぶと食べられて1点**。食べたお菓子は手持ちに戻ります。5つ並びは2点。
- 入れかえた**自分のお菓子は「恋モード」**（目がハート）になります。
- **ふつう同士**、**恋モード同士**なら入れかえOK。ふつうと恋モードは入れかえられないので、入れかえ返しはできません。恋モード同士で入れかえると、入れかえた側のお菓子は**目がさめて**ふつうに戻ります。空きマスへ動かすのはいつでもOK。
- 先に**3点**取った人の勝ち。150手で時間切れになり、その時点で点が多い人の勝ち。

盤の大きさ（5×5・6×6・7×7）・並べる数・目標点は画面下で変えられます。各プレイヤーは「人」と「CPU」を切り替えられます。
慣れてきたら7×7がおすすめです。上手い人同士だと、6×6では守りきられて引き分けが増えていきますが、7×7なら決着がつきやすくなります。
操作はドラッグでも、タップで選んでからタップでもできます。

## 実力はあるのか

`node tools/skill-test.js 600` で、強さの違うCPUを600試合ずつ戦わせました（1人 対 2人、席は公平に回す）。

| 1人の側 | 相手2人 | 1人の側の勝率 |
|---|---|---|
| 考える | 素人 | 76% |
| 素人 | 考える | 16% |
| 素人 | 欲張り | 99.5% |
| 素人 | 適当 | 100% |

実力差がなければ33%なので、実力ははっきり勝敗に出ます。

- **考える**：ゲーム内のCPU。1手先の盤を見て、自分と相手の「あと1つで揃う形」の数で手を選ぶ。特に、自分の手で次の人に道を開けていないかを見る。最後の1マスが空いている形だけでなく、入れかえで奪えば揃う形（ふつう同士・恋モード同士）も「あと1つ」として数える
- **素人**：目の前だけ見る。揃える・相手の「あと1つ」のマスをふさぐ・自分の「あと1つ」を増やす
- **欲張り**：揃えられるときだけ揃える。あとは適当
- **適当**：ランダム

素人と「考える」の差は、**動かした跡に空いたマスを次の人に使われないか**を見るかどうか。上達のコツはそこです。

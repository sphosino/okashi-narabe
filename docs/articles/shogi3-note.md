# 三人将棋をAIに何十万局も指させたら、二人将棋の常識が通じなかった

3人で1つの盤を囲む「三人将棋」を作って、そのAIを育てました。AIにはルールと勝ち負けだけを教えて、あとはAIどうしで何十万局も指させ、勝ち方を自分で覚えさせています。

そうしてできたAIの指し方を数えてみると、二人将棋の感覚ではありえない手がたくさん出てきました。この記事では、その中から面白かったものを紹介します。

## 三人将棋のルール

- 9×9の盤に、青（下から上へ）・赤（上から下へ）・緑（右から左へ）の3人
- 1人の駒は、玉・金2・銀2・飛・角・歩5。持ち駒に香と桂
- 玉を取られた人は脱落。最後に残った1人が勝ち
- もうひとつ、玉が敵陣の1段目に入れば、その場で勝ち（入玉）

（画像：shogi3-board.png）

## 発見1：ただで取られる捨て駒が、ほとんど損にならない

AIは序盤から、相手の玉のそばに飛車や角を打ちこみ、次の手でただで取られるような手をよく指します。

（画像：shogi3-sac.png）
世代182の自己対局の46手目。青が赤の玉のそば（９二）に飛車を打ち、次の手で赤が銀でただで取りました。

二人将棋なら、飛車をただで渡すのは大きな損です。ところが、AIの「勝てる見込み」は、この飛車を取られる前と後で、ほとんど変わっていません（36.1%から36.7%）。

なぜ損にならないのか。調べてみると、こういう形が見えてきました。

- ただで捨てる手のほとんどは、**次に指す人の玉のそば**に打つ王手です。次の人は、その駒を取るしかありません
- 次の人が取っている間に、手番は**3人目**に回ります。そして3人目は、王手で形が崩れた次の人の玉を、さらに攻めに来ることが多いのです
- もし捨てずにふつうの手を指していたら、次の人に自分が攻められやすい局面でした

つまり「駒を1枚払って、次の人の1手を『取る』に使わせ、その間に3人目に次の人を攻めてもらう」。打ち合わせなしの共闘のような形です。三人では、駒1枚の損は、残り2人のうち1人にだけ渡るので、二人将棋ほど痛くないのかもしれません。

ただ、これは数えて見えた形で、AIが本当にそう考えているのかまでは、まだ分かっていません。

## 発見2：駒数で大きくリードしても、勝てない

二人将棋なら、駒得はそのまま有利です。三人将棋では、そうなりませんでした。

- トップが2位に**12枚以上**の差をつけた局面でも、その人が勝つのは**30%**。3人の平均（33%）と変わりません
- 持ち駒を8枚以上ひとり占めしても、勝つのは**26%**
- 最初に脱落する人は、たいてい「リードしていた人」でした

リードした人は、残りの2人から順番に攻められます。三人将棋では「出る杭は打たれる」が、そのまま起きています。勝つには、目立たないことも大事なようです。

## 発見3：緑が不利。原因は1筋の香

学習が進むにつれて、緑の勝率がどんどん下がっていきました。

- はじめ：青 33%・赤 32%・緑 35%
- 強くなったあと：青 38%・赤 42%・緑 **20%**

原因を調べると、**青と赤が序盤に、緑の玉の筋（1筋）へ香を打ち、上下から挟む**指し方でした。最初の20手で、青と赤の両方が1筋に香を打つ対局が、6〜7割もありました。

（画像：shogi3-pin.png）
世代182の自己対局の10手目。赤が１三、青が１九に香を打っています。緑の玉は、これを嫌って3手目にはもう１五から２五へ逃げています。

手番の順番を変えても直らなかったので、初期配置の問題です。試しに、3人とも自分から見て同じ形に並べる配置にすると、3人の差は数ポイントまで縮まりました。

チェスでも囲碁でも、強い人どうしになるほど先手の有利がはっきりしてきたと言われます。三人将棋でも、AIが強くなるにつれて、緑の不利が見えてきたのだと思います。

## それでも、人はまだAIに勝てる

ここまで読むと、AIは強そうに見えますが、人が勝つこともまだあります。わたしの勝率は、AI 2人を相手にして**だいたい20%**です。3人で互角なら33%なので、まだAIのほうが強いですが、5回に1回くらいは勝てます。

勝ち方は、とにかく**隙を作らず、固める**ことです。

- AIは、発見1のただ捨てを「ほとんど損にならない」と軽く見ています
- なので、こちらは固めて守りながら、AIが捨ててくる駒を**拾い続けます**。取った駒は自分の持ち駒になるので、少しずつ駒が増えていきます
- AIの攻めをしのぎきったころには、こちらの持ち駒がたまっていて、そこから勝てます

AIどうしの対局では「固めて待つ人は、2人から順番に攻められて崩される」のですが、人が相手だと、AIの捨て駒の見積もりの甘さが、少しずつ効いてくるようです。

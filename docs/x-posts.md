# X の投稿の記録

「また遊ぼ」の X アカウントで出した投稿と、その反応を残していく。あとで「どんな投稿が人を呼んだか」を見返すため。

- 反応は投稿の2〜3日後に、X のアナリティクス（表示回数・いいね・リンクのクリック）と GA（その日にサイトに来た人）を見て書く
- リンクには、どの投稿から来たか分かるように `?from=x` などをつけてもよい（GA の「参照元」でも X からかは分かる）
- 140字（全角）まで
- **リンクは本文に入れず、自分の投稿への最初の返信に貼る**（2026-10-18 から）。X は外へのリンクつきの投稿を広げにくいと言われるため。本文は画像・投票・短い文で、面白さだけを伝える
- 〇択は、まず2週間・週3回くらいで試す。X の投票（本文）＋〇択のリンク（返信）の形と、お題の画像つきリンクの形を比べる
- 分析の話（合っているか分からないもの）より、「楽しい」「やられた自分」のような遊んだ感じを出す
